#
# Formát:
# TYP | ID/název | STAV | DOSUD OVĚŘENO | ZAPSÁNO KDE | DALŠÍ KROK | POZNÁMKA
#
# STAV: čeká / rozpracováno / dokončeno / blokováno
# Dokončeno znamená, že byl prověřen deklarovaný rozsah, nikoli že byla nalezena
# úplně každá historická akce. Rozsah rešerše musí být vždy výslovně uveden.
#
# Pravidla checkpointu:
# - Po každé menší dávce zapsat výsledky do příslušných ročních souborů a aktualizovat tento soubor.
# - Změny ukládat na GitHub průběžně, nečekat na dokončení celého roku nebo celé kapely.
# - Nikdy znovu neověřovat dokončený údaj bez důvodu; při opakované kontrole uvést proč.
# - Nová kapela nalezená v line-upu se přidá jako nový řádek se stavem čeká.
# - Pokud se běh přeruší, pokračovat od prvního řádku čeká/rozpracováno.
# - Každý záznam akce musí mít rok, datum, místo, line-up a zdroje v ročním events.txt/sources.txt.
# - Každý záznam kapely musí mít ověřenou identitu, zdroje a odkazy na doložené akce.
# - Neověřené stopy se nesmí označit jako dokončené.
#
